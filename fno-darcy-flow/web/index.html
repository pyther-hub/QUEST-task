FNO Darcy-flow surrogate, in your browser

−∇·(a∇u) = 1 on the unit square with u = 0 on the edge, 128×128 grid. Pick, draw or write a permeability a(x). A Fourier Neural Operator (ONNX on WebAssembly) predicts the pressure u(x), and a conjugate-gradient solver computes it exactly. Everything runs on this device.

JavaScript in x (left → right) and y (bottom → top) in [0, 1], evaluated only in this browser. sin, exp, hypot, PI, … work without a prefix. Snap on: true or > 0.5 gives 1, else 0.1. Snap off: clamped to [0.1, 1].

Keys: S solve · N random sample · ←→ prev/next · M next model · ⌘Z undo

The models were trained on two-phase fields made from 5 smooth random blobs. Shapes outside that family (thin lines, checkerboards, smooth values between 0.1 and 1) are out of distribution, and the difference panel shows what that costs. Timings are for one sample on this device: single-threaded WebAssembly for the FNO, plain JS for the solver. The first run after switching models includes warm-up.
