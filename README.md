# QUEST-task: FNO surrogate for Darcy flow

A Fourier Neural Operator (FNO) that learns the solution operator of 2D Darcy flow,

```
−∇·(a(x) ∇u(x)) = 1  on the unit square,  u = 0 on the boundary
```

mapping a permeability field `a(x)` to the pressure `u(x)` on a 128×128 grid, in the
[PDEBench](https://github.com/pdebench/PDEBench) setting (two-phase `a ∈ {0.1, 1}`, β = 1).

**Live demo: https://pyther-hub.github.io/QUEST-task/**

The demo runs entirely in your browser: the FNO is exported to ONNX and executed with
onnxruntime-web (WebAssembly), and a conjugate-gradient finite-volume solver in plain JS
computes the exact answer next to it. Pick a held-out test sample, draw your own permeability,
or type a function `a(x, y)`, then compare the FNO prediction with the solver and switch between
trained models.

## Training

Trained on Kaggle (2× T4, PyTorch DDP, mixed precision) with this notebook:
**https://www.kaggle.com/code/tensorpanda231/notebook863b71e5c1**
(the same as [`fno-darcy-flow/notebooks/02_train_ddp.ipynb`](fno-darcy-flow/notebooks/02_train_ddp.ipynb)).
Data is generated by [`01_generate_dataset.ipynb`](fno-darcy-flow/notebooks/01_generate_dataset.ipynb):
9,000 train / 500 val / 500 test samples, solved exactly with PDEBench's stencil.

| Model | Params | Epochs | Test relative L2 (500 samples) |
|---|---|---|---|
| v1 | 2,368,001 | 47 (early stop) | 2.52 % |
| v2 | 2,368,001 | 148 | **1.64 %** |

The notebook ends by converting the best checkpoint to ONNX (fp32 and fp16 weights) and reporting
the accuracy cost: on v2 both stay at 1.637 % test relL2, and the fp16-weight file is half the size (5 MB).

## Repository layout

```
fno-darcy-flow/
  src/           FNO model, data generation + solver, training (upstream: AbdullahRasheed45/fno-darcy-flow)
  notebooks/     01 generate dataset, 02 train with DDP (Kaggle)
  export/        FFT-free FNO (DFT matmuls) -> ONNX, fp16 export, web model manifest
  web/           the static browser demo deployed to GitHub Pages
  app/, deploy/  FastAPI server version + CPU Docker / Hugging Face Space
  tests/         pytest suite (+ node --test for the JS solver)
```

## Run locally

```bash
cd fno-darcy-flow
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt fastapi uvicorn httpx onnx onnxscript onnxruntime
python -m pytest -q                          # tests
python -m http.server 8001 -d web            # browser demo at http://127.0.0.1:8001
```

Pushing to `main` redeploys the demo through [`.github/workflows/pages.yml`](.github/workflows/pages.yml).
More detail on the original FNO / DDP code is in [`fno-darcy-flow/README.md`](fno-darcy-flow/README.md).
